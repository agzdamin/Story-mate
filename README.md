# Story-Mate 📖✨

Story-Mate is a fun, story-driven social application that allows users to meet new people through **themed conversations** and collaboratively create a story based on their chats.

---

## 🧠 Project Concept

In Story-Mate, users:

1. Sign up and create an account
2. Choose a **conversation theme** (e.g., Pirate 🏴‍☠️)
3. Are randomly matched with another user who selected the same theme
4. Start chatting in real time
5. Every message is processed via the **ChatGPT API** and rewritten to match the selected theme’s **style and tone**
6. Users can:
   - Continue chatting
   - Exchange contact information if they like each other
   - End the chat at any time
7. At the end of a conversation, users can **export a story** generated from their chat, written in the selected theme

The project focuses on creativity, entertainment, and AI-assisted social interaction.
